## 실행 방법

```bash
pnpm install
pnpm dev
```

브라우저에서 [http://localhost:5173](http://localhost:5173) 접속.

## 자주 쓰는 명령

| 명령                | 설명                          |
| ------------------- | ----------------------------- |
| `pnpm dev`          | 개발 서버 실행                |
| `pnpm build`        | 프로덕션 빌드 (`tsc -b` 포함) |
| `pnpm preview`      | 빌드 결과물 로컬 프리뷰       |
| `pnpm typecheck`    | TypeScript 타입체크           |
| `pnpm lint`         | ESLint 실행                   |
| `pnpm format`       | Prettier로 전체 포맷          |
| `pnpm format:check` | 포맷 위반만 확인 (CI용)       |
